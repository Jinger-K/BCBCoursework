#2
tail -n +2 ../data/fasta/e_coli.fasta

#This command displays all lines from the second line of e_coli.fasta. The header is excluded because it xontains descriptive information rather than sequence data. In "tail -n +2", "tail" prints the final part of a file, "-n" specifies the output in terms of lines, and "+2" means starting from the second line (whild "tail -n 2" prints only the last two lines").

#3
tail -n +2 ../data/fasta/e_coli.fasta | grep -o '[A-Z]' | wc -l
#or
tail -n +2 ../data/fasta/e_coli.fasta | xargs printf '%s' | wc -c

#These commands can both read the sequence lines without the header. The first one then finds all the letters, excluding newline characters, while the second one joins the sequence lines without newline characters. Finally they count to obtain the sequence length, and they have the same result.
